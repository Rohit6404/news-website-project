# 📰 News Website

A responsive news website built with **HTML, CSS, and JavaScript** that fetches news articles using the NewsAPI service. Search for topics and explore news across different categories through a simple, interactive interface.

## ✨ Features

- 🗞️ Fetches news articles from a news API
- 🔎 Search for news by keyword
- 🏏 Browse IPL news
- 💰 Explore Finance news
- 🏛️ Explore Politics news
- 🖼️ Displays article images, headlines, descriptions, and sources
- 🔗 Open the original article by clicking a news card
- 📱 CSS-based responsive layout

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure |
| CSS3 | Styling and layout |
| JavaScript | Dynamic content and interactions |
| Fetch API | HTTP requests |
| NewsAPI | News article data |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Rohit6404/news-website-project.git
```

### 2. Open the project

```bash
cd news-website-project
```

Open `index.html` in your browser, or use the Live Server extension in VS Code.

### 3. Configure the API key

Get an API key from [NewsAPI](https://newsapi.org/). Configure it locally in your JavaScript code without committing your real key to GitHub.

**Security note:** A key used directly in frontend JavaScript can be viewed by visitors. For a public deployment, use a backend API proxy to protect your key.
